# Masum Khandakar — Portfolio

AI video & ad films · Shopify stores · Websites.

A fast, hand-built static site (no framework, no build step).

## Update the content
Edit **`content.js`** — projects, contact details, socials, services, prices and FAQ all live there.

- Add a project: copy one line in `projects`, set `type` (`film`, `ad`, `shopify`, `web`), and paste a YouTube link into `video` or a live URL into `link`.
- Add contact: fill `contact.email` and/or `contact.whatsapp` — the brief form and contact cards switch on automatically.

## Deploy
Hosted on GitHub Pages from the `main` branch. Push to `main` and the site updates in about a minute.
